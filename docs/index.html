What is Soroban?

Soroban is Stellar's smart-contract platform. A smart contract is a program that runs on a network. DocForge helps explain the public interface in its source code; it does not deploy contracts or check a live contract.

Functions

Operations a user or another contract can call, such as transferring a token.

Types

Named shapes for the data a contract uses, such as a settings record or an error enum.

Events

Messages a contract emits so other applications can learn that something happened.

Generate and preview your docs

You need Go 1.23 or newer and a folder containing your Soroban Rust source.

1

Download DocForge

git clone https://github.com/toolnook/frontend.git
cd frontend
2

Scan and build

go run ./cmd/docforge scan \
  -dir /path/to/your-contract

go run ./cmd/docforge build \
  -dir /path/to/your-contract \
  -o ./generated-docs \
  -name MyContract
3

Preview locally

go run ./cmd/docforge serve \
  -d ./generated-docs

Open the local address printed in your terminal, usually http://localhost:8090.
